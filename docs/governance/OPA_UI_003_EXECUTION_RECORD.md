## 2. الفلاتر (FLT-001)

- كل عمود نصّي صار يقدّم **بحثًا حرًا + قائمة بالقيم الموجودة** مع تحديد متعدد (مثال: عميلان معًا).
- قوائم القيم تُجلب قراءةً فقط: أسماء العملاء وأرقام الفواتير (حد 500، `staleTime` 5 دقائق) مع حالة تحميل.
- الدلالة: قيم متعددة داخل العمود = OR، بين الأعمدة = AND؛ القيم المختارة لها الأولوية على النص الحر.
- الترجمة إلى PostgREST: `in` لأكثر من قيمة، `eq` لقيمة واحدة (`applyColumnFilters`).
